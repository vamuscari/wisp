1. Setup                                                         *wisp-setup*

Run `wisp deploy`, add its stable `nvim` directory to 'runtimepath', then call:
>
  require("wisp").setup()
<
The deployed adapter always invokes the executable from its own bundle. Wisp
opens in a floating terminal. A project selection sets the originating tab's
local working directory. Enter on a file first reuses a matching visible normal
file window. Otherwise, the selected target creates a tab page, right vertical
split, or bottom horizontal split. Ctrl-T, Ctrl-V, and Ctrl-X force those three
targets without reuse. File browsing uses retained directory columns:
highlighting a folder loads only its immediate children on a debounced worker,
Enter or Right descends, and Left or Backspace returns to its parent. Superseded
folder results are discarded. The originating normal-file buffer is shown
inline on the current project together with the Git branch and configurable
clean/dirty, untracked, modified, staged, conflicted, upstream, and stashed
markers. Nonzero category counts are shown. Git metadata loads after the picker
opens. Editor activity does not make a project host-open or closable.

Inside WezTerm, Wisp publishes strict protocol-v8 viewport state for every
normal file window in the current Neovim tab. Unnamed and non-file buffers,
including terminals, quickfix lists, help, and file-tree buffers, are omitted.
Buffer, tab, and window changes publish immediately; cursor, scroll, and resize
updates use one short debounce.

File Preview renders plain text inside Wisp's own terminal UI. Press p in Files
mode to hide or show it. Set file_preview = true to start with it visible. Wisp
loads files on a debounced background worker, reads at most 1 MiB or 10,000
lines, and reports binary, non-UTF-8, missing, or unreadable files inline. The
adapter creates no companion float or temporary sidecar.

The Neovim adapter disables OpenCode session mode. Session focus and attach
actions are currently implemented only by the WezTerm adapter.

The tab-local variables `wisp_project_dir` and `wisp_project_name` contain the
selected project metadata. They are initially seeded from $WISP_PROJECT_DIR
and $WISP_PROJECT_NAME when those variables are present.

:Wisp                   Open the picker. The command name is configurable.

3. Options                                                      *wisp-options*

Pass options to setup():
>
  require("wisp").setup({
    keymap = "<leader>p",
    config_file = "/path/to/wisp/config.toml",
    width = 0.8,
    height = 0.7,
    border = "rounded",
    file_open = { default = "window" },
    file_preview = true,
  })
<
`config_file`       Optional shared TOML path.
`command`           User command name. Default: "Wisp".
`keymap`            Optional normal-mode mapping.
`keymap_options`    Options passed to vim.keymap.set().
`width`, `height`   Fractions up to 1, or absolute cell counts.
`border`            Border accepted by nvim_open_win().
`file_open`         Exact table with default set to "window", "right_pane", or
                    "bottom_pane". Default: { default = "window" }.
`file_preview`      Boolean. Start with Wisp's internal file Preview visible.
                    Default: false; p can still show it on demand.
